# Harish Thombare — Civil Engineering Portfolio

Responsive portfolio website made with HTML, CSS and JavaScript.

## Folder structure
```text
Harish_Portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── Harish_Thombare_Resume.pdf
```

## Run locally
1. Extract `Harish_Portfolio.zip`.
2. Open the folder in VS Code.
3. Ensure the resume PDF is inside `assets` and named `Harish_Thombare_Resume.pdf`.
4. Open `index.html` in a browser, or use the VS Code Live Server extension and click **Go Live**.

## Update details
Edit `index.html` to update the name, email, phone, LinkedIn URL, education, skills or other content. Use accurate, verified details.

## Resume
Place the PDF at `assets/Harish_Thombare_Resume.pdf`. The View Resume and Download Resume links already use this path.

## Deploy with GitHub + Netlify
1. Create a new GitHub repository, e.g. `harish-civil-portfolio`.
2. Upload all files and the `assets` folder. Keep `index.html` in the repository root.
3. In Netlify, choose **Add new site → Import an existing project** and connect GitHub.
4. Select the repository. Leave the build command blank and set publish directory to `.`.
5. Deploy. Netlify will provide a public website URL.

## Content accuracy
The website uses the education, skills, coursework and contact details supplied in the resume. It does not invent projects, internships, certificates or employment history. Add these when verified information is available.
