# Harish Thombare – Civil Engineering Portfolio

A responsive and animated personal portfolio website built using **HTML, CSS, and JavaScript**.

## Features
- Responsive design for desktop and mobile.
- Smooth scrolling and entrance animations.
- Animated sections and interactive hover effects.
- Skills and educational background.
- Resume viewing and downloading.
- Contact and LinkedIn information.

## Folder Structure
```text
Harish_Portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── Harish_Thombare_Resume.pdf
```

## Run Locally
1. Extract the project ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the VS Code Live Server extension and click **Go Live**.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Resume
The resume is stored in `assets/Harish_Thombare_Resume.pdf`.

## Deployment
This portfolio can be deployed using GitHub Pages or Netlify.

For Netlify:
1. Connect your GitHub repository.
2. Leave the build command blank.
3. Set the publish directory to `.`.
4. Click Deploy.

## Content Accuracy
The portfolio uses verified education, skills, coursework and contact details supplied in the resume. Projects, internships and certifications can be added when verified information is available.
